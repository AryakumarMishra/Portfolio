# Aryakumar Mishra — Portfolio

A premium, editorial portfolio for an **AI Systems Engineer**—designed like a modern SaaS product, not a traditional résumé site.

## Positioning

Communicates: *I design, build, evaluate, and deploy intelligent systems*—LLM apps, ML pipelines, AI security, MLOps, and production backends.

## Design philosophy

Calm, minimal, and craft-forward—inspired by Linear, Vercel, Stripe, Raycast, and Apple. Generous whitespace, exceptional typography, soft glass surfaces, restrained accent glows, and spring-based micro-interactions. Understated neural-field motifs only—no cliché AI imagery.

## Stack

- **Next.js** (App Router)
- **TypeScript**
- **Tailwind CSS v4**
- **Framer Motion**
- **Geist** typography

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Project structure

```
src/
  app/                 # App router entry, layout, styles
  components/
    layout/            # Navbar, Footer
    motion/            # Reveal, stagger animations
    sections/          # Hero, Work, About, Capabilities, Experience, Contact
    ui/                # Button, Section, GradientBlobs
  lib/                 # Content data, utilities
```

## Customization

Edit personal content in `src/lib/data.ts`—name, projects, experience, social links, and copy.
